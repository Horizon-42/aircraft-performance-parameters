Aircraft Performance Parameters

Open per-type parameters for point-mass aircraft performance models: mass, geometry, drag polar, landing lift, thrust and reference speeds. Every value carries the document it came from and its licence. Built for terminal-area approach modelling; released under GPL-3.0.

Downloads

  • recommended.csv — one row per aircraft type, one value per field (chosen by a fixed source priority), with a <field>_source column.
  • parameters.csv — every value from every source, one row each (typecode, field, value, unit, source_id, locator, derived, note).
  • sources.csv — every document cited, with URL, revision, sha256 and licence.
  • substitutions.csv — "type X uses type Y's parameters" statements from OpenAP, Poll–Schumann and our own analysis.
  • fields.csv — field dictionary with units and source priority.

Read before use

Derived CL,max. No public source gives a landing CL,max. We compute it from the FAA approach speed at maximum landing weight: Vs = Vapp/f, CL,max = 2mg / (ρ₀ S Vs²), with f = 1.23 (current certification, VREF ≥ 1.23 VSR) and f = 1.3 (FAA approach category, 1.3 VSO). The IAS is taken as sea-level EAS (no position-error or compressibility correction). This is an approximation.
One code, several variants. An ICAO designator often covers several certified models. Sources may describe different variants (for example B763 MTOW 158.7 t vs 186.9 t). recommended.csv picks one value; parameters.csv shows them all.
Drag polar coverage. CD0, k, e, gear and flap terms come only from OpenAP (37 types). Poll–Schumann's own drag parameters (ψ₀, δ₂, sweep) are listed as ps_* fields and are not converted, because CD0 = Cf(Re)·ψ₀ depends on Reynolds number.
Not yet collected. Flap deflection angles, VFE, VLE and VLO are defined fields but empty in this release.

What is deliberately not here

  • BADA (EUROCONTROL): its licence makes the datasets and any results derived from them confidential.
  • EASA ANP: its terms forbid publication without the data provider's written consent.
  • EUROCONTROL Aircraft Performance Database: copyright permission is required.
  • Verbatim text from manufacturer documents and books: only the factual value and its page are kept.

Data licence: GPL-3.0 (OpenAP's data licence carries over). Poll–Schumann values: Apache-2.0, see NOTICE. FAA values: US government work. EASA values: reproduced with acknowledgement.
